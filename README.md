# 专注花园 / Focus Garden

Windows 与 Android 离线番茄钟，把任务、资料、本地音乐和专注记录放在一起。无需账号，不提供云同步。

## 下载与升级

从 [GitHub Releases](https://github.com/navihouse/focus-garden/releases) 获取正式包：

- **Windows 10/11 x64**：下载 Windows-x64.zip，完整解压后运行 focus_garden.exe，保留 DLL 和 data 文件夹。升级前从旧版托盘选择“保存并退出”。
- **Android 8.0 及以上**：下载 Android.apk，覆盖安装即可；官方包沿用同一签名。卸载前请先备份。
- SHA256SUMS.txt 用于核对安装包完整性。

## 1.7.0：任务排序与备注文件链接

### 大任务拖动排序

在任务页或专注页，按住未完成任务右侧三个点拖动，即可调整大任务顺序。两页共用顺序，自动保存，重启和备份合并后保留；轻点三个点仍打开原任务菜单。拖动不改变任务状态、关联记录或正在进行的计时。

已完成任务继续收纳到默认折叠的“已完成 N”，按完成时间倒序；新任务放在未完成列表前方。编辑名称、备注等不会打乱已有手动顺序。

### 备注中的本地文件链接

任务详情的备注支持两种添加方式：

1. 粘贴完整本地文件路径，单独一行，或用双引号包住含空格的路径；支持中文、空格和 file:/// 地址。
2. 点击“添加本地文件链接”，填写地址或通过系统选择器选文件，可同时填写显示名称。

Windows 按住 **Ctrl 再单击链接**，使用系统默认程序打开文件；普通单击仍用于编辑。右键链接选择“修改链接显示名称”，只改变备注中的文字，原文件名与打开地址保持不变。右键菜单也可打开文件。完成编辑后需保存任务，取消放弃本次备注修改。

Android 可长按链接后选择打开或改名；选择器选中的文件保存为应用本地副本。不同设备的文件路径不会自动对应，文件丢失或没有打开程序时会提示。应用不上传或同步链接指向的文件。

## 其他功能

- 25 / 5 / 15 分钟默认专注、短休息、长休息，可自定义；每完成 4 次长休息。专注结束响铃并自动休息，休息结束使用不同声音，下一次专注手动开始。
- 任务支持科目 / 项目、截止日期、预计番茄数（1–999）、子任务、拖动排序、备注、删除及完成提示音。
- 本地 MP3、FLAC、WAV、M4A、OGG、AAC，播放列表、顺序 / 随机 / 循环、切歌、音量和静音；音乐故障不影响计时。
- Windows 托盘、开机自启动、开始菜单搜索、专注置顶、自定义全局快捷键。默认 Ctrl+Shift+空格控制音乐，Ctrl+Alt+空格控制当前计时暂停 / 继续。
- 自定义背景、浅色 / 深色主题、图片可见度及独立卡片透明度（0%–100%）。
- 周 / 月 / 年报告、时段分析、中断分布、科目排名、热力图与周期目标。
- JSON 备份预览、UUID 去重、任务冲突选择、重叠提醒与整批回滚。

## 记录与统计口径

单次实际专注不足一分钟为“无效自习”，保留历史与备份，不计入任何统计和番茄数；满 60 秒参与统计，完整番茄仍须跑完计划时长。暂停、休息不计时，手动排除的记录不参与分析。

采用北京时间 UTC+8、周一开始、自然月和自然年。先按整次实际专注判断有效，再拆分跨日 / 跨周期时长，完成与中断次数归入结束日期。少于 5 个有效样本不生成规律建议；投入最多不代表效率最高。每 15 秒保存检查点，异常恢复不补记未知时间。

## 备份与隐私

1.7.0 使用 **版本 4 备份**，保存任务顺序、备注显示文字及本地文件目标，兼容导入版本 1–4。两端均需升级到 1.7.0 后交换新备份，旧应用无法导入版本 4。旧备注仍保留原文，旧任务首次拖动前沿用原有顺序。

备份包含个人任务、学习记录及备注中的文件地址；请自行保管。备份不包含链接指向的文件内容、音乐、壁纸、正在进行的计时或设备设置，文件需要在各设备分别准备。

源码和 Release 不包含个人任务、数据库、音乐、原始壁纸、文件附件、日志、凭据或签名密钥。上传前检查实际暂存文件与安装包内容，见 [隐私检查](PRIVACY_CHECK.md)。

## 使用与构建

- [完整使用说明](app/README.md)
- [构建与原生验证](app/scripts/README.md)

源码包括 app/lib 的 Flutter 界面与领域逻辑、app/android 的 Kotlin 后台 / Media3 服务、app/windows 的原生系统集成，以及 app/test 与 app/test_support 的自动和隔离验证。

工具链为 Flutter 3.47.7 / Dart 3.13.5、SQLite / Drift、JDK 21 与平台开发工具。

```sh
cd app
flutter pub get
flutter analyze
flutter test
flutter build windows --release --target lib/main.dart
flutter build apk --release --target lib/main.dart
```

Android 自行构建需配置自己的签名材料；官方私人密钥不在仓库中。无密钥 CI 产出未签名 APK，正式发布前本机签名校验。Windows 包包含必要运行库。

## 验证范围

自动测试、静态检查及两端构建用于验证源码和产物。Windows 原生文件打开和系统快捷键另有隔离验证入口。Android 真机锁屏、电池策略、外部文件打开和 ColorOS 16 / 荣耀 400 MagicOS 10 胶囊展示仍需设备验收；系统决定胶囊是否出现及系统卡片布局。

不含云同步、AI 复盘、PDF 或 CSV 报告导出。
