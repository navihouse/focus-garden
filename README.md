# 专注花园 / Focus Garden

**一边专注，一边听自己的音乐；把任务、学习资料和每次投入留在本机。**

专注花园是一款面向 Windows 与 Android 的离线番茄钟。你可以围绕任务计时、播放已保存的本地音乐，再用周报、月报和年报回顾投入情况。无需注册账号，两端通过备份文件手动合并记录。

当前正式版本：**1.9.0（12）**。

## 下载与安装

在 [GitHub Releases](https://github.com/navihouse/focus-garden/releases) 下载最新正式包，也可查看 [1.9.0 发布说明](https://github.com/navihouse/focus-garden/releases/tag/v1.9.0)。

| 平台 | 下载文件 | 如何安装 |
| --- | --- | --- |
| Windows 10 / 11，64 位 | 文件名以 `Windows-x64.zip` 结尾的压缩包 | **完整解压**后运行 `focus_garden.exe`，保留同目录的 DLL 和 `data` 文件夹 |
| Android 8.0 及以上 | 文件名以 `Android.apk` 结尾的安装包 | 在手机打开 APK，按系统提示安装；官方新版可直接覆盖安装 |
| 完整性校验 | `SHA256SUMS.txt` | 用于核对两个安装包的 SHA-256 校验值，不是安装程序 |

**升级时：**Windows 先在旧版系统托盘右键选择“保存并退出”，再打开新版本。Android 建议直接覆盖安装；卸载或清除应用数据前，先导出备份。

## 快速上手

1. **添加一个任务。**进入“任务”页，点击“新建”，填写任务名称、科目或项目、预计番茄数。还可以添加截止日期、子任务和备注，完成后点击“保存”。
2. **准备背景音乐。**进入“音乐库”，新建或选中一个歌单，再点击“添加文件”选择本地音频。不听音乐也能正常计时；Windows 待机时可以先试听。
3. **开始专注。**进入“专注”页，选择任务，或保留“自由专注”，点击“开始专注”。默认专注 25 分钟，短休息 5 分钟，每完成 4 次专注后长休息 15 分钟。
4. **按自己的节奏控制。**“暂停计时 / 继续计时”控制番茄钟；音乐有独立的播放按钮。专注开始自动播放音乐，暂停、结束或休息时暂停音乐。
5. **结束后回顾。**专注到点会响铃并自动休息；休息结束播放不同提示音，下一次专注由你手动开始。在“历史记录”查看单次明细，在“统计报告”切换周报、月报、年报和历史周期。

右上角的设置按钮可以修改时长、主题、背景图片、目标和 Windows 快捷键。修改计时时长从下一次计时生效。

Android 首次使用时，在专注页点击“开启提醒权限”，按提示允许通知和准确提醒；部分手机还需要在系统电池设置中允许后台运行。Android 16 及以上可进入“实时通知设置”开启相应权限，点击计时通知可查看已专注 / 剩余时间卡片。系统胶囊是否出现由手机系统决定。

## 功能亮点

| 亮点 | 能帮你做什么 |
| --- | --- |
| **离线使用，数据留在本机** | 不用账号；任务、记录、音乐与学习资料不依赖应用服务器 |
| **计时与本地音乐联动** | 只播放当前歌单，支持顺序、随机和循环；暂停和休息时暂停，音乐故障不停止计时 |
| **从大任务落到下一步** | 支持子任务、备注、父子任务拖动排序和完成提示音；已完成任务折叠收纳 |
| **资料就在任务旁边** | 在备注添加本地文件链接，用简短名称显示，Ctrl 点击打开原文件 |
| **回顾真实投入** | 按实际专注时长生成报告，展示时段分布、中断情况和番茄数前三科目的投入 |
| **适合桌面常驻** | Windows 支持托盘、开机自启动、开始菜单搜索、专注置顶和自定义全局快捷键 |
| **手机上的计时入口** | Android 提供后台计时服务、通知栏控制和已专注 / 剩余时间卡片，锁屏表现仍需对应设备验证 |
| **界面可以自己调** | 深浅主题、自定义背景图片，图片可见度和卡片透明度分别设置 |
| **电脑与手机手动合并** | 备份导入先预览，按 UUID 去重，任务冲突可选择版本，失败时整批回滚 |

## 常用操作

### 管理任务与子任务

- 点击任务名称打开详情；**只有点击左侧圆环才标记大任务完成**。完成时响铃，再次点击可恢复待办。
- 在“添加下一步”填写子任务后按 Enter，可以连续录入；子任务勾选完成也会响铃。
- 按住右侧三个点拖动排序：大任务在专注页和任务页共用顺序、自动保存；子任务的排序与其他详情修改需点击“保存”。
- 轻点三个点打开菜单。大任务可确认删除，子任务可删除；删除任务会保留已有专注历史。
- 点击“已完成 N”展开收纳区，最近完成的排在前面。已完成任务不参与手动排序，编辑内容不会改变其完成时间。
- “预计番茄数”只接收最多三位数字，保存范围为 **1–999**。

### 把本地资料放进备注

打开任务详情，在备注下方点击“添加本地文件链接”，填写完整地址，或点击“选择本地文件”，然后填写可选的显示名称。

例如，把 `D:\Study\大学物理\第一章讲义.pdf` 显示成“第一章讲义”。**显示名称与打开目标分开保存，改名不会重命名或移动原文件。**

- **Windows 打开：**按住 Ctrl，再单击备注中的下划线链接；普通单击仍用于编辑文字。
- **修改名称：**右键链接，选择“修改链接显示名称”；右键菜单也可直接打开文件。
- **直接粘贴：**支持本机完整路径及 `file:///` 地址；建议每个地址独占一行，同一行多个路径请分别用双引号包住。中文、空格和括号均支持。
- **保存修改：**备注及链接改名需保存任务，取消则放弃草稿；删除引用不会删除原文件。
- **Android：**可长按链接打开或改名；通过选择器添加的文件复制到应用本地目录。

文件被移动、删除、当前设备无权访问或没有对应打开程序时，会显示提示。链接指向的文件不会随任务备份传输；跨设备需要分别准备文件并设置正确地址。

### 用歌单管理和播放音乐

音乐库按文件夹式歌单分类，升级后的原有歌曲自动保留在“默认歌单”，不会重新导入或移动原文件。

1. 点击“新建歌单”，填写名称并“创建并打开”；也可以选择已有歌单。
2. 在选中的歌单点击“添加文件”，可一次选多首。支持普通 **MP3、FLAC、WAV、M4A、OGG、AAC**。
3. 点击歌曲或播放按钮开始播放。播放、切歌、随机与循环都限定在**当前歌单**，不会把其他歌单的歌曲混入队列。
4. 歌曲右侧菜单可“移动到歌单”“复制到歌单”或“从当前歌单移除”；同一目标歌单中相同路径不会重复添加。
5. 歌单菜单可重命名或确认删除。重命名不打断播放；删除歌单或移除歌曲只删除引用，不删除原音频，也不影响其他歌单。

“专注”页的“播放歌单”下拉框也能切换歌单。正在播放时，切换后从新歌单第一首继续；切到空歌单、新建空歌单或移除最后一首会停止播放。删除当前歌单会停止音乐并选择剩余歌单，不自动播放；删除其他歌单保持当前播放。暂停、休息和静音状态下切换或点歌不会强行恢复音乐。

Windows 引用原文件，移动音乐后需重新添加；Android 导入时复制到应用目录，复制或移动到其他歌单共享本地引用。实际能否播放取决于文件编码，受保护或加密的会员缓存不属于普通音频文件。

Windows 待机可试听，不会生成专注记录；Android 继续沿用专注期间播放的规则。音乐静音与完成提示音独立。歌单、当前选择和播放模式保存在本机，不随任务备份传输；卸载 Android 会删除本地音乐副本。

### 使用快捷键、托盘与置顶

| Windows 默认快捷键 | 操作 |
| --- | --- |
| Ctrl + Shift + 空格 | 音乐播放 / 暂停 |
| Ctrl + Alt + 空格 | 当前计时暂停 / 继续，不会从待机开始新番茄 |

在设置中点击对应快捷键的“修改”，按新组合键后保存，也可恢复默认。支持 Ctrl 或 Alt 配合字母、数字、空格、F1–F11，可加 Shift；两组按键不能相同，被系统或其他程序占用时会提示并保留原设置。

窗口最小化或关闭后仍在托盘运行，右键托盘可打开或“保存并退出”。设置中的“开机自启动”默认关闭，开启后登录 Windows 时进入托盘，不自动计时或播放。按 Win 键搜索 `FocusGarden` 或“专注花园”可打开应用，移动程序后可在设置中修复开始菜单入口。

专注页右上角图钉可将窗口置顶、仅显示专注页，再次点击恢复；置顶状态不跨重启保存。

### 自定义背景与卡片透明度

设置中选择静态 JPG、JPEG、PNG 或 WebP，原图限制 20 MB。图片会转存为应用自己的本地副本，删除原图不影响背景。

- **图片可见度**控制背景图与主题底色的混合程度。
- **卡片透明度**默认 65%，0% 不透明、100% 完全透明；文字与操作控件不会整体变淡。

设置内可预览，保存后生效；移除背景并保存后恢复普通卡片。图片和设备设置不随任务备份传输。

## 怎样看懂统计

进入“统计报告”，选择周报、月报或年报，再切换本期或历史周期。

| 报告 | 主要内容 |
| --- | --- |
| 周报 | 每日专注、完成与中断次数、任务分布、逐小时投入 |
| 月报 | 本月专注热力图、每日趋势、每周投入、活跃天数、科目占比、最长连续专注天数 |
| 年报 | 每月投入、全年热力图、累计时长、任务与科目分布 |

三个周期都提供平均单次时长、完成率、可选目标完成度、活跃与低投入时段、中断钟点与阶段，以及完整番茄数前三科目的逐小时投入。

**月报热力图：**按周一至周日排列当月日期，颜色按本月每日实际专注时长由浅到深显示，灰色表示零投入，空格是月外日期。鼠标悬停或手机点击日期可查看当天分钟数；切换月份后重新计算色阶，不适合仅凭颜色跨月比较。无有效记录时明确提示空数据。

理解数据时请记住：

- **实际专注不足 60 秒是“无效自习”。**记录保留在历史与备份中，但不计入时长、番茄数、活跃天数、完成率、中断分析或建议样本。刚好 60 秒有效。
- **有效不等于完成。**满一分钟后提前结束，可计入有效时长和未完成次数；只有跑完计划时长才算一个完整番茄，不按 25 分钟统一折算。
- 暂停、休息不计时；手动排除的记录不参与统计。统计统一使用北京时间 UTC+8，周一开始，自然月和自然年。
- 跨日先按整次专注判断有效，再拆分到各日期；完成和中断次数归入结束日期。
- “低投入”只比较有专注记录的小时，零投入表示暂无记录；投入最多不代表效率最高，也不推断情绪。
- 不足 5 个有效样本时只展示原始分布，不生成规律建议。中断图的百分比表示占未完成记录的比例，不是某个时段的“中断概率”。
- 当前周期标注进行中，不用于完整周期环比；缺少目标或历史基准时不生成百分比。

专注运行时每 15 秒保存检查点，关键操作立即保存。异常退出、电脑睡眠或重启后，只保留最后可靠时间，不补算未知间隔。

## 备份、迁移与隐私

右上角“备份与合并”→导出 JSON，手动传到另一台设备后选择“导入并预览”。建议先结束当前计时再导出。

相同记录按 UUID 去重；任务冲突默认保留本机版本，可改用导入版本。重叠时段会提示并允许排除误记，导入失败整批回滚。

| 会进入备份 | 不会进入备份 |
| --- | --- |
| 任务及顺序、子任务、备注、链接地址与显示文字、完成时间、已保存的专注记录 | 歌单、音乐、链接指向的文件内容、背景图片、正在进行的计时和本机设置 |

**备份版本兼容关系：**

| 应用版本 | 导出的备份版本 | 可导入版本 |
| --- | --- | --- |
| 1.0.x | 1 | 1 |
| 1.1.0–1.4.0 | 2 | 1、2 |
| 1.5.0–1.6.0 | 3 | 1、2、3 |
| 1.7.0–1.9.0 | 4 | 1、2、3、4 |

电脑与手机请都升级到 1.7.0 或以上后再交换版本 4 备份，旧版应用无法导入版本 4。旧任务和普通备注仍可读取，无需改写专注历史。

应用不提供云同步，备份包含个人学习记录及本地文件地址，请自行保管。源码与 Release 不包含个人任务、数据库、音乐、壁纸、附件、运行日志、凭据或私人签名材料，检查方式见 [PRIVACY_CHECK.md](PRIVACY_CHECK.md)。
