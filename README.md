# 专注花园 / Focus Garden

**一边专注，一边听自己的音乐；把任务、学习资料和每次投入留在本机。**

专注花园是一款面向 Windows 与 Android 的离线番茄钟。你可以围绕任务计时、播放已保存的本地音乐，再用周报、月报和年报回顾投入情况。无需注册账号，两端通过备份文件手动合并记录。

当前版本：**1.14.0（18）**。安装包与校验文件见 [GitHub Releases](https://github.com/navihouse/focus-garden/releases/tag/v1.14.0)。

## 下载与安装

在 [GitHub Releases](https://github.com/navihouse/focus-garden/releases) 下载最新正式包，也可查看 [1.14.0 发布说明](https://github.com/navihouse/focus-garden/releases/tag/v1.14.0)。

| 平台 | 下载文件 | 如何安装 |
| --- | --- | --- |
| Windows 10 / 11，64 位 | 文件名以 `Windows-x64.zip` 结尾的压缩包 | **完整解压**后运行 `focus_garden.exe`，保留同目录的 DLL 和 `data` 文件夹 |
| Android 8.0 及以上 | 文件名以 `Android.apk` 结尾的安装包 | 在手机打开 APK，按系统提示安装；官方新版可直接覆盖安装 |
| 完整性校验 | `SHA256SUMS.txt` | 用于核对两个安装包的 SHA-256 校验值，不是安装程序 |

**升级时：**Windows 先在旧版系统托盘右键选择“保存并退出”，再打开新版本。Android 建议直接覆盖安装；卸载或清除应用数据前，先导出备份。

## 快速上手

1. **添加一个任务。**进入“任务”页，点击“新建”，填写任务名称、科目或项目、预计番茄数。还可以添加截止日期、子任务和备注，完成后点击“保存”。
2. **准备背景音乐。**进入“音乐库”，新建或选中一个歌单，再点击“添加文件”选择本地音频。不听音乐也能正常计时；Windows 待机时可以先试听。
3. **开始专注。**进入“专注”页，选择任务，或保留“自由专注”，点击“开始专注”。默认专注 25 分钟，短休息 5 分钟，每完成 4 次专注后长休息 15 分钟。
4. **按自己的节奏控制。**“暂停计时 / 继续计时”控制番茄钟；音乐有独立的播放按钮。专注开始自动播放音乐，暂停、结束或休息时暂停音乐。
5. **结束后回顾。**专注到点会响铃并自动休息；休息结束播放不同提示音，下一次专注由你手动开始。在“历史记录”查看单次明细，在“统计报告”切换周报、月报、年报和历史周期。

右上角的设置按钮可以修改时长、主题、背景图片、目标和 Windows 快捷键。修改计时时长从下一次计时生效。

Android 首次使用时，在专注页点击“开启提醒权限”，按提示允许通知和准确提醒；部分手机还需要在系统电池设置中允许后台运行。Android 16 及以上可进入“实时通知设置”开启相应权限，点击计时通知可查看已专注 / 剩余时间卡片。系统胶囊是否出现由手机系统决定。

## 功能亮点

| 亮点 | 能帮你做什么 |
| --- | --- |
| **离线使用，数据留在本机** | 不用账号；任务、记录、音乐与学习资料不依赖应用服务器 |
| **计时与本地音乐联动** | 只播放当前歌单，可在列表循环、单曲循环和随机播放之间切换；暂停和休息时暂停 |
| **从大任务落到下一步** | 支持子任务、备注、父子任务拖动排序和完成提示音；已完成任务折叠收纳 |
| **任务可以分组** | 分组名称和颜色都能自定义，按组折叠、跨组拖放和组内排序；专注记录不受影响 |
| **AUTO 自动整理** | 定时生成今日任务摘要；Windows 调用已有脚本采集学习通 / 中国大学MOOC 待办，按来源去重 |
| **资料就在任务旁边** | 在备注添加本地文件和网页链接，可自定义显示名称 |
| **回顾真实投入** | 按实际专注时长生成报告，展示时段分布、中断情况和番茄数前三科目的投入 |
| **适合桌面常驻** | Windows 支持托盘、开机自启动、开始菜单搜索、专注置顶和自定义全局快捷键 |
| **手机上的计时入口** | Android 提供后台计时服务、通知栏控制和已专注 / 剩余时间卡片，锁屏表现仍需对应设备验证 |
| **界面可以自己调** | 深浅主题、自定义背景图片，图片可见度和卡片透明度分别设置 |
| **电脑与手机手动合并** | 备份导入先预览，按 UUID 去重，任务冲突可选择版本，失败时整批回滚 |

## 常用操作

### 管理任务与子任务

- 点击任务名称打开详情；**只有点击左侧圆环才标记大任务完成**。完成时响铃，再次点击可恢复待办。
- 在“添加下一步”填写子任务后按 Enter，可以连续录入；子任务勾选完成也会响铃。
- 按住右侧三个点拖动排序：大任务在专注页和任务页共用顺序、自动保存；子任务的排序与其他详情修改需点击“保存”。
- 轻点三个点打开菜单。大任务可确认删除，子任务可删除；删除任务会保留已有专注历史。
- 点击“已完成 N”展开收纳区，最近完成的排在前面。已完成任务不参与手动排序，编辑内容不会改变其完成时间。
- “预计番茄数”只接收最多三位数字，保存范围为 **1–999**。

### 给任务分组

- 任务页点击“分组”打开分组管理，可新建、改名、改颜色或删除分组。按住分组右侧三个点拖动排序，松手后自动保存，轻点仍可打开编辑和删除菜单。名称最多 40 字，同一份任务里不能重名。
- 在任务页或专注页也可直接按住**组标题整行**拖动到另一组标题，调整顺序并自动保存；点击标题仍是展开 / 收起。拖到“未分组”标题可排到最后，“未分组”始终在自建组之后。
- 在新建任务或任务详情上方的“任务分组”下拉框里选择所属分组，也可以留空保持“未分组”。
- 任务页按分组分段显示，点击整行组标题展开，再次点击收起；空分组也会显示；按住任务右侧三个点，拖到组标题或空组区域即可加入该组，拖到“未分组”即可移出。拖到任务卡片上半部或下半部可插到它的前面或后面，松手后自动保存。
- 添加任务时就选好分组，可以省去事后整理。分组只影响列表展示，不计入统计，也不改变已有的专注记录。

### AUTO：今日开始与学习平台采集

导航栏在“任务”下方增加 **AUTO**。在“今日开始”开启每日发送，设置时间（默认 08:00，北京时间），或点击“生成今日开始”。新摘要出现后，AUTO 右上角显示红点；打开摘要后标记已读。收件箱保留发送时的任务快照，可点击“查看任务”打开最新详情。

- **今日截止**：截止日期为今天的任务。
- **昨日完成**：昨天标记完成、当前仍为完成状态的任务。
- **昨日未完成**：昨天截止、发送摘要时仍未完成的任务；更早的逾期任务不混入此栏目。

定时功能在软件打开或托盘运行时执行。完全退出时不运行；重新打开后补发当天已经到时间的摘要，每天一封，不为关闭期间的每一天逐日补发。摘要与采集均默认关闭。若希望摘要包含当天新采集的任务，先完成采集再生成摘要。

**Windows 设置采集：**

1. 打开 AUTO →“学习平台采集”→“配置采集”，选择 Python 程序、采集脚本和需要的平台。Python 须已安装 `requests`（可用 `python -m pip install requests` 安装）。
2. 使用已有脚本 `D:\Pomodoro Technique\study-scraper\study_scraper.py`；安装包也附带同一份脚本，移动到其他电脑时默认使用内置副本，可另选脚本。
3. 在浏览器登录自己的学习平台，将请求中的 Cookie 内容保存为本机文本文件，分别选择学习通、MOOC Cookie 文件。只填写所选平台；Cookie 属于登录凭据，请自行保管，无需发送给他人或提交到仓库。可沿用原脚本的 `cookies/chaoxing.txt` 和 `cookies/icourse163.txt`。
4. 选择新任务保存的分组，保存后先点“立即采集”。结果显示新增、更新和保留数量；作业、考试、测验 / 测试按课程归类，备注包含来源和原任务链接，有截止时间的保留到秒。
5. 开启每日采集并选择时间（默认 07:30）。软件打开或托盘运行时执行，重开后补跑当天已到时间的采集；一次运行尚未结束时不重复启动。失败会提示原因，当天可手动重试，下一天继续定时执行。

在 AUTO → 学习平台采集 → **过期任务规则** 可选择“忽略所有已过期”“超过 7 天”“超过 30 天”“自定义天数（0–3650）”或“不忽略”。默认忽略所有已过期。7 天按整 168 小时，30 天按整 720 小时，恰好 N 天的记录保留，超过才忽略；未来任务不受此规则影响。没有截止时间时不推断过期天数；默认模式下仍忽略平台明确标记已过期的任务。

规则同时应用于脚本输出和 JSON 导入，采集结果显示忽略过期数量。规则不会删除已有任务；之前因过期被跳过的任务，在放宽规则后可以重新采集。已提交、已完成或已批阅的任务仍不导入。脚本也可单独使用 `--ignore-expired-days 7`，`0` 表示忽略所有已过期，`-1` 表示不按过期过滤。若手动选择了旧脚本，请更新为本版本附带脚本，确保识别新参数。

任务详情中的 **截止日期和时间** 合并为一项：点击“选择日期和时间”，确认日期后自动进入时间填写，使用北京时间 24 小时制。时间下方勾选“全天”，即可只保存日期。时间窗口取消时整次截止修改不生效，保留原值；清除按钮同时清除日期和时间。

同一平台任务按来源编号去重。后续采集更新未被手动修改的名称、课程和截止时间，保留本机完成状态、分组、备注和子任务；已完成或已删除的自动任务不会被重新创建。来源暂时缺失不会删除任务，也不会推断它已经完成。多个平台部分失败时仅导入成功来源，并明确提示不完整。

**手机端**可使用“今日开始”，并通过“导入采集结果”导入脚本生成的 `todos.json`，或通过备份接收电脑版任务；Python 定时采集仅在 Windows 运行。AUTO 设置、Cookie 地址、收件箱和采集去重记录仅存在本机，不随任务备份传输。

真实平台的登录状态与网页接口可能变化。离线测试和模拟采集不代表真实账号采集已通过；Cookie 过期或接口变化时，应用会提示检查配置与网络。采集不会提交作业、参加考试或修改平台内容。

### 在备注中添加文件和网页

打开任务详情，在备注下方点击“添加本地文件链接”，填写完整地址，或点击“选择本地文件”，然后填写可选的显示名称。

点击“添加网页链接”，粘贴完整的 HTTP 或 HTTPS 地址。可以用“课程主页”之类的名称显示；留空则显示网址。插入后记得保存任务。

例如，把 `D:\Study\大学物理\第一章讲义.pdf` 显示成“第一章讲义”。**显示名称与打开目标分开保存，改名不会重命名或移动原文件。**

- **Windows 打开：**按住 Ctrl，再单击备注中的下划线链接；普通单击仍用于编辑文字。
- **修改名称：**右键链接，选择“修改链接显示名称”；右键菜单也可直接打开文件或网页。网页交给系统浏览器或对应应用打开。
- **直接粘贴：**支持本机完整路径及 `file:///` 地址；建议每个地址独占一行，同一行多个路径请分别用双引号包住。中文、空格和括号均支持。
- **保存修改：**备注及链接改名需保存任务，取消则放弃草稿；删除引用不会删除原文件。
- **Android：**可长按链接打开或改名；通过选择器添加的文件复制到应用本地目录。

文件被移动、删除、当前设备无权访问或没有对应打开程序时，会显示提示。链接指向的文件不会随任务备份传输；跨设备需要分别准备文件并设置正确地址。

### 用歌单管理和播放音乐

音乐库按文件夹式歌单分类，升级后的原有歌曲自动保留在“默认歌单”，不会重新导入或移动原文件。

1. 点击“新建歌单”，填写名称并“创建并打开”；也可以选择已有歌单。
2. 在选中的歌单点击“添加文件”，可一次选多首。支持普通 **MP3、FLAC、WAV、M4A、OGG、AAC**。
3. 点击歌曲或播放按钮开始播放。默认列表循环，最后一首结束后回到第一首。开启随机后自动关闭循环，随机队列播完即停；再次点击随机或点击循环，恢复列表循环。在列表循环时点循环按钮，可切到单曲循环。切歌和播放都限定在**当前歌单**。
4. 歌曲右侧菜单可“移动到歌单”“复制到歌单”或“从当前歌单移除”；同一目标歌单中相同路径不会重复添加。
5. 歌单菜单可重命名或确认删除。重命名不打断播放；删除歌单或移除歌曲只删除引用，不删除原音频，也不影响其他歌单。

“专注”页的“播放歌单”下拉框也能切换歌单。正在播放时，切换后从新歌单第一首继续；切到空歌单、新建空歌单或移除最后一首会停止播放。删除当前歌单会停止音乐并选择剩余歌单，不自动播放；删除其他歌单保持当前播放。暂停、休息和静音状态下切换或点歌不会强行恢复音乐。

Windows 引用原文件，移动音乐后需重新添加；Android 导入时复制到应用目录，复制或移动到其他歌单共享本地引用。实际能否播放取决于文件编码，受保护或加密的会员缓存不属于普通音频文件。

Windows 待机可试听，不会生成专注记录；Android 继续沿用专注期间播放的规则。音乐静音与完成提示音独立。歌单、当前选择和播放模式保存在本机，不随任务备份传输；卸载 Android 会删除本地音乐副本。

### 使用快捷键、托盘与置顶

| Windows 默认快捷键 | 操作 |
| --- | --- |
| Ctrl + Shift + 空格 | 音乐播放 / 暂停 |
| Ctrl + Shift + → | 播放前一首 |
| Ctrl + Shift + ← | 播放后一首 |
| Ctrl + Alt + 空格 | 当前计时暂停 / 继续，不会从待机开始新番茄 |

在设置中点击对应快捷键的“修改”，按新组合键后保存，也可恢复默认。支持 Ctrl 或 Alt 配合字母、数字、空格、左右方向键、F1–F11，可加 Shift；四组按键不能相同，被系统或其他程序占用时会提示并保留原设置。

窗口最小化或关闭后仍在托盘运行，右键托盘可打开或“保存并退出”。设置中的“开机自启动”默认关闭，开启后登录 Windows 时进入托盘，不自动计时或播放。按 Win 键搜索 `FocusGarden` 或“专注花园”可打开应用，移动程序后可在设置中修复开始菜单入口。

专注页右上角图钉可将窗口置顶、仅显示专注页，再次点击恢复；置顶状态不跨重启保存。

### 自定义背景与卡片透明度

设置中选择静态 JPG、JPEG、PNG 或 WebP，原图限制 20 MB。图片会转存为应用自己的本地副本，删除原图不影响背景。

- **图片可见度**控制背景图与主题底色的混合程度。
- **卡片透明度**默认 65%，0% 不透明、100% 完全透明；文字与操作控件不会整体变淡。

设置内可预览，保存后生效；移除背景并保存后恢复普通卡片。图片和设备设置不随任务备份传输。

## 怎样看懂统计

进入“统计报告”，选择周报、月报或年报，再切换本期或历史周期。

| 报告 | 主要内容 |
| --- | --- |
| 周报 | 每日专注、完成与中断次数、任务分布、逐小时投入 |
| 月报 | 本月专注热力图、每日趋势、每周投入、活跃天数、科目占比、最长连续专注天数 |
| 年报 | 每月投入、全年热力图、累计时长、任务与科目分布 |

三个周期都提供平均单次时长、完成率、可选目标完成度、活跃与低投入时段、中断钟点与阶段，以及完整番茄数前三科目的逐小时投入。

**月报布局：**宽屏中热力图在左、每日趋势在右，窄屏自动上下排列。趋势图底部在内容超宽时显示可拖动的横向滚动条，拖至最右可查看月底日期；悬停或点击柱形可查看对应分钟数。切换月份后回到该月起点。

**月报热力图：**按周一至周日排列当月日期，颜色按本月每日实际专注时长由浅到深显示，灰色表示零投入，空格是月外日期。鼠标悬停或手机点击日期可查看当天分钟数；切换月份后重新计算色阶，不适合仅凭颜色跨月比较。无有效记录时明确提示空数据。

理解数据时请记住：

- **实际专注不足 60 秒是“无效自习”。**记录保留在历史与备份中，但不计入时长、番茄数、活跃天数、完成率、中断分析或建议样本。刚好 60 秒有效。
- **有效不等于完成。**满一分钟后提前结束，可计入有效时长和未完成次数；只有跑完计划时长才算一个完整番茄，不按 25 分钟统一折算。
- 暂停、休息不计时；手动排除的记录不参与统计。统计统一使用北京时间 UTC+8，周一开始，自然月和自然年。
- 跨日先按整次专注判断有效，再拆分到各日期；完成和中断次数归入结束日期。
- “低投入”只比较有专注记录的小时，零投入表示暂无记录；投入最多不代表效率最高，也不推断情绪。
- 不足 5 个有效样本时只展示原始分布，不生成规律建议。中断图的百分比表示占未完成记录的比例，不是某个时段的“中断概率”。
- 当前周期标注进行中，不用于完整周期环比；缺少目标或历史基准时不生成百分比。

专注运行时每 15 秒保存检查点，关键操作立即保存。异常退出、电脑睡眠或重启后，只保留最后可靠时间，不补算未知间隔。

## 备份、迁移与隐私

右上角“备份与合并”→导出 JSON，手动传到另一台设备后选择“导入并预览”。建议先结束当前计时再导出。

相同记录按 UUID 去重；任务冲突默认保留本机版本，可改用导入版本。重叠时段会提示并允许排除误记，导入失败整批回滚。

| 会进入备份 | 不会进入备份 |
| --- | --- |
| 任务及顺序、子任务、备注、链接地址与显示文字、完成时间、任务分组及组内顺序、已保存的专注记录 | 歌单、音乐、链接指向的文件内容、背景图片、正在进行的计时和本机设置 |

**备份版本兼容关系：**

| 应用版本 | 导出的备份版本 | 可导入版本 |
| --- | --- | --- |
| 1.0.x | 1 | 1 |
| 1.1.0–1.4.0 | 2 | 1、2 |
| 1.5.0–1.6.0 | 3 | 1、2、3 |
| 1.7.0–1.10.0 | 4 | 1、2、3、4 |
| 1.11.0 | 无网页链接时为 4，有网页链接时为 5 | 1、2、3、4、5 |
| 1.12.0 | 含任务分组时为 6；不含分组时同 1.11.0 | 1、2、3、4、5、6 |
| 1.13.0–1.14.0 | 含精确截止时间时为 7；否则沿用 1.12.0 规则 | 1–7 |

含精确截止时间的版本 7 备份需要两端升级至 1.13.0 或以上。普通日期任务仍按原版本规则导出；任务详情可选择截止时间，清除时间则恢复仅日期。

含任务分组的备份需要两端都升级到 1.12.0 或以上；不含分组时仍按 1.11.0 的规则导出，可与旧版交换。导入第 6 版备份时，同 UUID 或同名的分组会合并到已有分组，组内任务随之归入。含网页链接的备份需要两端都升级到 1.11.0 或以上；只含本地文件链接的版本 4 备份仍可与 1.7.0–1.10.0 交换。旧任务和普通备注仍可读取，无需改写专注历史。

应用不提供云同步，备份包含个人学习记录和备注中的文件地址、网址，请自行保管。源码与 Release 不包含个人任务、数据库、音乐、壁纸、附件、运行日志、凭据或私人签名材料，检查方式见 [PRIVACY_CHECK.md](PRIVACY_CHECK.md)。
