# 专注花园 / Focus Garden

Windows 与 Android 离线番茄钟，把任务、本地音乐和专注记录放在一起，按周、月、年查看投入与时段分布。无需账号，不提供云同步。

## 下载与安装

在 [GitHub Releases](https://github.com/navihouse/focus-garden/releases) 下载正式版本：

- **Windows 10/11 x64**：下载 Windows-x64.zip，完整解压后运行 focus_garden.exe，保留同目录 DLL 与 data 文件夹。更新前在旧版托盘选择“保存并退出”。
- **Android 8.0 及以上**：下载 Android.apk。官方版本使用同一签名，可覆盖升级；卸载前先备份。
- SHA256SUMS.txt 提供安装包校验值。

## 1.6.0 新增

- **自定义 Windows 全局快捷键**：在设置中录入新组合键，可恢复默认；重复或被占用的按键会提示，保存失败保留原配置。
- **有效自习门槛**：单次实际专注不足一分钟，仅保留为“无效自习”历史，不计入番茄数、任务累计、周期报告或任何时段分析。满 60 秒可参与统计；暂停、休息不计时，完整番茄仍须跑完计划时长。
- **透明背景卡片**：使用自定义图片时卡片默认半透明，图片可见度与卡片透明度分别调节。卡片支持 0%–100% 透明度和效果预览，移除图片后恢复普通界面。

## 功能

- 可调专注、短休息和长休息，默认 25 / 5 / 15 分钟；每完成 4 次后长休息。专注结束提示并自动休息，休息结束用不同声音提醒，下一次专注手动开始。
- 任务支持科目 / 项目、截止日期、预计番茄数（1–999）、子任务、备注、拖动排序；完成任务默认折叠收纳，按完成时间倒序排列。任务与子任务完成均有提示音。
- 本地 MP3、FLAC、WAV、M4A、OGG、AAC，播放列表、切歌、音量、静音、随机和循环；计时与音乐联动，Windows 待机可试听，解码失败不影响计时。
- Windows 托盘、开机自启动、开始菜单搜索、专注窗口置顶、自定义全局快捷键。
- Android 后台计时、Media3 播放、通知栏控制、实时通知接入，以及已专注 / 剩余时间卡片。
- 周 / 月 / 年报告：趋势、热力图、活跃天数、完成率、任务 / 科目分布、投入时段、中断分布、番茄数前三科目的逐小时投入。
- JSON 备份与手动合并：预览、UUID 去重、任务冲突选择、重叠提醒与事务回滚。

## 统计口径与隐私

采用北京时间 UTC+8，周一开始，自然月和自然年。实际时长跨午夜分摊，完成 / 中断次数归入结束日期。有效性按整次实际专注判断，再拆分到报告周期；跨日分片不足一分钟仍计入。

无效自习和手动排除记录不参与任何统计，包括完成率分母、中断分布、活跃天数及建议样本数。不足 5 个有效样本只展示分布，不生成规律建议；投入最多不代表效率最高。每 15 秒保存检查点，异常恢复不补算未知时间。

记录保存在本地 SQLite，报告随原始记录重新计算。备份仍为版本 3，兼容导入版本 1、2、3；1.6.0 无需修改原始记录或备份格式，旧记录自动应用新规则。音乐、图片、快捷键及透明度留在本机，不随任务备份传输。

源码与 Release 不含个人任务、数据库、音乐、壁纸、日志、凭据及签名密钥；上传前检查实际暂存内容，见 [隐私检查](PRIVACY_CHECK.md)。

## 使用与开发

- [完整使用说明](app/README.md)
- [构建与原生验证](app/scripts/README.md)
- app/lib：Flutter 界面、任务、计时、音乐、统计和备份。
- app/android：Kotlin 后台计时、Media3、通知及专注卡片。
- app/windows：音频、睡眠事件、系统快捷键与启动集成。
- app/test、app/test_support：自动测试与隔离数据的原生验证入口。

工具链：Flutter 3.47.7 / Dart 3.13.5、SQLite / Drift、JDK 21 及平台工具。

```sh
cd app
flutter pub get
flutter analyze
flutter test
flutter build windows --release --target lib/main.dart
flutter build apk --release --target lib/main.dart
```

Android 自行构建需配置自己的签名材料；官方私人密钥不在仓库中。CI 无密钥时产出未签名 APK，正式发布前在本机签名校验。Windows 发布包附带必要运行库。

## 验证边界

静态检查、自动测试和两端构建验证代码与产物。Android 真机锁屏、电池策略、ColorOS 16 / 荣耀 400 MagicOS 10 胶囊展示仍需实机验收：系统决定胶囊展示及系统卡片布局，点击计时通知可打开应用自己的左右计时卡片。

不含云同步、AI 复盘、PDF 或 CSV 报告导出。
