# 专注花园 1.8.0 使用说明

Windows 与 Android 离线番茄钟，无需登录。任务、音乐及记录保存在设备本地。

首次使用可先阅读 [快速上手](../README.md#快速上手)；功能亮点、版本兼容关系与 1.0.0–1.8.0 更新历史见 [项目 README](../README.md#更新历史)。本页保留完整操作说明。

## 安装与升级

Windows 下载正式压缩包，完整解压后打开 focus_garden.exe，保留 DLL 与 data 文件夹。首次运行添加开始菜单入口，按 Win 键搜索 FocusGarden 或“专注花园”即可打开。移动程序后可在设置中修复入口。

更新前在旧版托盘右键选择“保存并退出”，再从新目录启动。记录位于系统应用支持目录，不与程序目录一起替换。

Android 正式 APK 使用原签名，覆盖安装即可。卸载会删除应用数据和导入文件，卸载前先备份。

## 开始专注

1. 在任务页填写任务名称、科目 / 项目、截止日期和预计番茄数。预计数只接受最多三位 ASCII 数字，保存范围 1–999。
2. 在音乐库先选择或新建歌单，再点击“添加文件”导入本地音频，也可以无音乐计时。
3. 专注页关联任务或直接开始。默认专注 25 分钟、短休息 5 分钟，每完成 4 次后长休息 15 分钟。设置修改从下一次计时生效。
4. 专注到点播放上行双音并自动开始休息；休息到点播放下行三音，下一次专注手动开始。提前结束不自动休息。

暂停、休息不计入实际专注。开始专注自动播放，暂停、结束、休息时暂停音乐；计时与音乐按钮独立。Windows 待机可试听，不生成记录。音乐故障不停止计时；提示音独立于音乐静音，受系统音量影响。

## 有效自习与历史

**单次实际专注不足 60 秒为“无效自习”。** 保留原始历史和备份，可在历史页筛选“无效自习”，但不计入时长、任务累计、番茄数、活跃天数、完成率、平均时长、中断分布、科目排名或建议样本数。恢复手动排除状态不能绕过一分钟门槛。

刚好 60 秒有效；满一分钟但提前结束，计入有效时长及未完成次数，不算完整番茄。完整番茄必须跑完计划时长，不按 25 分钟折算。暂停一小时不会将 30 秒专注变为有效。

新规则适用于旧记录、导入记录和异常恢复，不删除或改写原始时长。跨日 / 周 / 月 / 年先按整次实际专注判断，再分摊周期时长。例如跨年一分钟，两个年份各计 30 秒时长，番茄数归入结束年份。

每 15 秒保存检查点，暂停、结束等关键动作立即保存。电脑睡眠、设备重启、异常退出只保留最后可靠时间，不补算未知间隔；正常手机锁屏继续。历史可查看计划 / 实际时长、起止时间、专注与暂停区间、设备及结束原因。误记可手动排除，所有统计随之更新。

## 大任务顺序与子任务

在任务页或专注页，按住未完成大任务右侧三个点拖动排序，边缘可自动滚动。两页顺序一致并自动保存，重启后保留；轻点三个点仍打开状态 / 删除菜单。编辑任务不改变手动顺序，新任务放在列表前方。已完成任务继续折叠收纳、按完成时间倒序，不参与手动排序。

- 点击任务名称打开详情，顶部名称固定；可编辑科目、日期、多行备注及子任务。
- “添加下一步”输入后按 Enter 连续录入；编辑已有子任务时 Enter 进入下一条。按住右侧三个点拖动排序，轻点可删除。
- 仅点击任务左侧圆环才标记完成，并播放“叮”声；再次点击恢复待办。子任务勾选完成立即响铃，取消勾选不响铃；编辑需保存，取消放弃草稿。
- 完成的任务放入默认折叠的“已完成 N”，展开后最近完成的在前。编辑不改变完成时间，恢复后重新完成会更新完成时间；旧任务缺少完成时间时使用修改时间。
- 任务右侧菜单可删除任务及其子任务、备注，需确认；历史与正在计时的任务快照保留。
- Windows 专注页右上角图钉可将窗口置顶并隐藏其他页面入口，再次点击恢复，不跨重启保存。

## 备注中的本地文件链接

任务详情中的备注仍支持普通文字，也可插入本地文件链接。点击“添加本地文件链接”，填完整地址或点击“选择本地文件”，可填写一个简短显示名称。比如显示“物理讲义”，实际仍打开原来的 PDF。

也可以直接粘贴完整路径：建议每个地址单独一行，包含空格、中文、括号的文件名均支持；同一行多个地址请分别用双引号包住。支持本机盘符路径和 file:/// 文件地址，不接受网页地址或命令作为文件目标。

- Windows 按住 **Ctrl + 单击**下划线链接，使用系统默认程序打开；普通单击用于放置光标和编辑。
- 右键链接，选择“修改链接显示名称”，只修改备注中文字，不重命名文件，也不改变打开目标；也可在菜单中直接打开文件。
- 地址被别名替代后仍可 Ctrl 点击打开原文件。编辑链接前后的文字会相应调整位置，删除链接则只删除备注引用，不删除原文件。撤销可恢复备注及链接。
- 备注编辑与改名需点击任务“保存”；取消放弃本次修改。任务拖动顺序自动保存，不依赖详情保存按钮。
- Android 长按链接可打开菜单；通过文件选择器选中的文件复制到应用目录以保留访问。直接填写其他应用的私有路径或不可访问路径无法打开，请通过选择器重新添加。
- 文件移动、删除、跨设备路径不对应或系统没有打开程序时显示错误，保留备注与目标。链接不是文件附件同步，备份只带文字与地址。

每条备注最多 10000 字、200 个文件链接。Windows 引用原文件；Android 本地副本会随卸载或清除应用数据删除。更换设备需自行准备文件并重新添加正确地址。

## 背景与透明卡片

设置中选择静态 JPG / JPEG / PNG / WebP，限制 20 MB。导入时缩小至最长边 2560 像素，保存为应用自己的 PNG；删除原图不影响背景。

选择图片后有两项独立设置：

- **图片可见度**：调节图片与主题底色的混合程度。
- **卡片透明度**：默认 65%，0% 不透明、100% 完全透明。仅改变卡片底色，文字、图表与操作控件不会整体变淡。

设置内提供即时效果预览，保存后应用于专注、任务、音乐库、历史和报告。取消保留原样，移除图片并保存恢复普通不透明卡片。深浅主题均支持。图片与透明度仅保存本机，不进入备份或仓库。

## Windows 自定义全局快捷键

| 操作 | 默认按键 |
| --- | --- |
| 音乐播放 / 暂停 | Ctrl + Shift + 空格 |
| 当前计时暂停 / 继续 | Ctrl + Alt + 空格 |

在设置中点击对应操作的“修改”，按下组合键后保存。支持 **Ctrl 或 Alt + 字母、数字、空格、F1–F11**，可同时加 Shift；不接受单键、仅 Shift、Win 键或保留的 F12。按 Esc 或取消退出录入；恢复默认也需保存。

录入期间暂时停用本应用快捷键以避免误操作，录入后自动恢复。两组按键不能相同；保存检查系统占用，失败显示错误并保留原配置，成功释放旧按键，重启后保持。被其他程序占用时可以修改或保存重试。

快捷键在应用运行、最小化和托盘时有效。计时快捷键不从待机开始新番茄，音乐快捷键仍遵守暂停、休息与静音联动。

关闭或最小化窗口后应用留在托盘，右键可打开或保存退出。设置中可启用开机自启动，登录后只进入托盘，不自动计时或播放；移动目录后重新保存可更新启动路径。

## 歌单与本地音乐

音乐库以文件夹式歌单管理歌曲，原来的平铺音乐列表自动保留为“默认歌单”。无需重新导入，原文件路径与歌曲名称保持不变。

- 点击“新建歌单”，输入 1–80 字的非重复名称，再“创建并打开”。选中歌单后点“添加文件”，支持多选普通 MP3、FLAC、WAV、M4A、OGG、AAC。
- 点击文件夹或在专注页的“播放歌单”中选择歌单。所有播放、上一首 / 下一首、随机和单曲 / 列表循环，都只访问该歌单内的歌曲。
- 正在播放时切换歌单，会从新歌单第一首继续；切换空歌单、新建空歌单、移除最后一首会停止音乐。计时暂停、休息或音乐静音时，切换或点歌保持暂停。
- 歌单右侧菜单可重命名或删除。重命名不会重载正在播放的歌曲；删除当前歌单会停止播放，选中剩余歌单但不自动播放。删除其他歌单不影响当前音乐。删除最后一个歌单后会保留一个空的默认歌单。
- 歌曲菜单支持移动、复制到其他歌单及从当前歌单移除；目标已有同一路径时不重复添加。复制 / 移动只整理歌单引用，不移动或删除原音频；同一文件可被多个歌单使用。
- Windows 引用原文件路径，移动文件后需重新添加。Android 导入时保存本地副本，在歌单间复制或移动会共用副本；卸载或清除应用数据会删除副本。
- 当前歌单和随机 / 循环模式保存在本机，歌单和音乐不随任务备份传输，两端分别管理。实际解码依赖文件编码和平台，不支持加密的会员缓存。

Windows 待机可试听；Android 沿用开始专注后播放的规则。音乐与计时按钮分开，音乐故障不影响计时；暂停、结束和休息时仍自动暂停音乐。

## 报告与分析

周报、月报、年报可切换当前或历史周期。使用北京时间 UTC+8、周一开始、自然月和自然年；时长按日期 / 小时分摊，完整番茄与中断次数按结束日期归属。

- 每日 / 每月趋势、每周投入、全年热力图、累计时长、任务 / 科目分布、活跃天数、最长连续专注天数。
- 平均时长仅累计本期贡献，完成率按本期结束记录计算，跨期时两者涉及的记录集合可能不同。
- 投入最多与最少的各三个小时，只比较有记录的时段，并列标注；零投入表示暂无记录，不推断效率或情绪。
- 中断原因分为提前结束、电脑睡眠、退出应用及异常中断；结束钟点归类，异常可能只代表最后检查点。
- 中断阶段按实际专注占计划时长划分前 25%、25%–50%、50%–75%、最后 25%，边界归入后一阶段，暂停不计进度。柱形比例为占有效未完成记录的比例，不是“中断概率”。
- 前三科目按完整番茄数、实际投入、名称依次排名，至少有一个本期完整番茄才参与；展示时长（含有效未完成记录）与逐小时分布，未分类单独提示。
- 有时长贡献或本期结束的有效记录各计一个样本，不重复；不足 5 个样本只展示分布，不生成规律建议。至少 5 次有效结束记录且中断率达 30% 时建议尝试缩短单次时长。
- 可设置周 / 月 / 年分钟目标；进行中的周期不展示完整周期环比，缺少目标或历史基准时显示缺失状态。

无效自习和排除记录不参与以上统计。报告由原始数据重新生成，导入合并后更新，周期结束后下次打开即可查看。

## Android 后台与卡片

在专注页允许通知与准确提醒，部分手机需额外允许后台运行。正常锁屏继续；系统强行停止后不自行恢复。

Android 16 及以上接入实时通知，系统支持时可显示胶囊 / 灵动岛入口；需允许普通通知和实时通知。胶囊展示、手势和系统卡片布局由系统决定。点击计时通知可打开应用自己的左右计时卡片，显示实际已专注和剩余时间，支持暂停 / 继续，使用原后台计时，不另开计时器。休息时显示已休息与休息剩余。

ColorOS 16 / 荣耀 400 MagicOS 10 仍需用户真机验收，旧系统继续使用普通通知。编译和自动测试不替代锁屏、电池策略、耳机断开或通知拒绝的设备测试。

## 备份与合并

右上角“备份与合并”导出 JSON，再手动传到另一端导入。建议先结束当前计时。备份含任务顺序、子任务、备注、文件链接地址、完成时间和保存记录；不含链接对应的文件内容、歌单、音乐、图片、正在进行的计时或本机设置。

备份版本为 4，兼容导入 1、2、3、4；两端都升级到 1.7.0 后交换新备份，旧应用无法读取版本 4。新增任务顺序、链接显示文字及目标地址，旧记录仍可读取，无需改写专注历史。

导入先预览，相同 UUID 跳过并保留本机排除状态；任务冲突默认本机版本，也可选择导入版本。重叠记录提示并允许排除误记，未排除的有效记录分别累计。失败整批回滚，不影响已有数据。备份包含个人学习记录，请自行保管。

## 开发

Flutter 3.47.7、SQLite / Drift、Windows media_kit 与原生集成、Android Kotlin / Media3。详见 [构建说明](scripts/README.md)。

```powershell
cd 'D:\Pomodoro Technique\app'
.\scripts\dev.ps1 -Action analyze
.\scripts\dev.ps1 -Action test
.\scripts\dev.ps1 -Action windows
.\scripts\prepare-signing.ps1
.\scripts\dev.ps1 -Action android
```

P: 是开发脚本为带空格目录创建的临时盘符别名，开发进程退出后可用 subst P: /d 释放。SDK、缓存、构建产物及私人签名材料不纳入 Git。
