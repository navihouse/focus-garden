# 专注花园

Windows 与 Android 离线番茄钟。没有账号、服务器、AI 接口或云端上传；音乐和记录存储在设备本地。

## 使用

1. 在任务页添加任务，可填写科目或项目、截止日期、预计番茄数和状态。点击任务打开详情，可添加、勾选、改名、排序或删除子任务，并填写多行备注；点击“保存”后生效。

   1.3.1 将任务名称固定在详情顶部，滚动子任务、备注或日期时仍然可见，长名称可自动换行。子任务从未完成勾选为完成时立即播放一次“叮”声；取消勾选、编辑名称及点击保存不会重复播放。编辑仍需保存，取消则放弃草稿；声音失败不撤销勾选。
2. 在音乐库添加普通音频文件。Windows 使用原文件路径，移动后需重新添加；Android 复制到应用本地目录，卸载后副本删除。
3. 专注页可关联任务或直接开始。默认专注 25 分钟、短休息 5 分钟，每完成 4 次后长休息 15 分钟，时长在设置中调整。
4. 专注开始自动播放音乐，暂停、结束和休息时暂停音乐。音乐按钮只控制音乐，计时有独立按钮。音乐故障不停止计时。
   Windows 1.0.1 起，待机时可以在音乐库点击播放试听，不必先开始专注，也不会生成专注记录。计时暂停与休息期间仍暂停音乐；静音时点击播放会提示先取消静音。
5. 专注到点播放上行双音，并自动开始短休息；每完成 4 次改为长休息。休息到点播放不同的下行三音并停止，下一次专注需要手动开始。提前结束只保留实际时间，标记未完成，不自动进入休息。
6. Windows 最小化和关闭窗口后仍在系统托盘运行，右键托盘图标选择“保存并退出”。
7. Android 专注页可开启通知与准确提醒权限，可能需要分两次操作。部分手机需在系统电池设置中允许后台运行。系统强行停止应用后不会自行恢复计时。

支持普通 MP3、FLAC、WAV、M4A、OGG、AAC 文件。实际解码能力由播放器及文件编码决定，失败会显示提示。无音乐时也可计时。

## 任务与专注操作（1.2.0 起）

- 填写“添加下一步”后按 Enter，当前子任务会加入列表，输入焦点留在新的空白输入栏，可连续录入；编辑已有子任务时按 Enter 会进入下一条。
- 按住子任务右侧的三个点拖动排序，轻点三个点只显示“删除子任务”。保存任务后保留顺序，取消则放弃本次编辑。
- 点击任务名称打开详情；只有点击左侧圆环才标记完成。完成后播放独立提示音，任务排到所有已完成任务之后；再次点击圆环恢复待办。编辑和状态菜单均不提供完成操作。
- 大任务右侧菜单可删除任务，确认后删除子任务及备注，保留已有专注历史；正在运行的计时保留原任务快照。
- 专注页也可以查看和处理任务。Windows 专注页右上角的图钉会将窗口置于普通窗口之上，隐藏其他页面导航、设置和备份入口；再次点击图钉解除置顶并恢复导航。置顶状态不跨重启保存。
- 完成提示音独立于音乐播放和音乐静音。1.3.0 两端使用更清脆的合成短铃声，任务完成、专注结束、休息结束采用三种不同音型，受系统音量与输出设备影响。声音故障不撤销任务完成，也不阻止计时阶段切换。系统通知关闭默认声音，避免和合成提示音叠加。

## Windows 启动入口（1.1.0 起）

- 首次打开程序会为当前 Windows 用户添加开始菜单入口。之后按 Win 键，搜索 `FocusGarden` 或“专注花园”即可打开。
- 右上角“设置”中可开启“开机自启动”，点击“保存”后生效；默认关闭。启用后登录 Windows 时仅进入系统托盘，不自动开始计时或播放音乐。取消勾选并保存即可关闭。
- 请保留解压后的完整程序文件夹。移动文件夹后，从新位置打开程序，在设置中点击“添加 / 修复开始菜单入口”；已启用自启动时再次保存设置可更新路径。
- 自启动使用当前用户的 Run 注册表项，开始菜单使用当前用户的 Programs 文件夹，无需管理员权限。测试入口使用隔离数据，不替换正式快捷方式。

## 记录和报告

- 实际时长不含暂停、休息。一次完整计时算一个番茄，不把不同长度强行折算为 25 分钟。
- 每 15 秒保存检查点，关键动作立即保存。异常退出、电脑睡眠或重启只保留最后确认时间，不补记未知间隔；手机正常锁屏继续。
- 固定使用北京时间 UTC+8，周一开始，自然月和自然年。跨日时长拆分，完成和中断次数归入结束日期。
- 平均单次按本期有投入的记录计算，仅累计本期部分；完成率按本期结束记录计算，因此跨期时两个指标涉及的记录集合可能不同。
- 未结束的本期不展示完整周期环比；没有目标或历史基准时显示缺失状态。目标值使用当前设置。
- 报告按原始记录动态计算，周期结束后下次打开即可查看，不要求周期切换时应用正在运行。
- 不足 5 次记录提示数据不足；至少 5 次且未完成率达到 30% 时建议缩短单次时长。投入最多的时段不等于学习效率最高。
- 历史记录可筛选并查看专注、暂停区间、设备及结束原因。误记可排除统计或恢复。

## 两端合并

右上角“备份与合并”导出 JSON，传到另一设备导入。备份包含任务与已保存记录，不含音乐、正在进行的计时或本机设置；导出前请先结束当前计时。

1.1.0 使用版本 2 备份，包含子任务和备注，并兼容导入旧版备份。两端都升级到 1.1.0 后再导入新备份；旧版应用无法读取版本 2 备份。

导入先预览：相同 UUID 跳过，已有记录的本机排除状态保持不变；任务冲突默认保留本机版本，可逐项采用导入版本。时间重叠时提示并允许排除误记，未排除的记录分别累计。数据库事务保证失败整批回滚。

卸载 Android 应用前请先备份。Windows 记录位于系统应用支持目录，不与可执行文件放在一起。

## 开发

工具在上一级 `work/`，实际项目与产物位于 `D:\Pomodoro Technique`。微软安装器管理的 Windows SDK 等系统共享组件使用系统目录。

```powershell
cd 'D:\Pomodoro Technique\app'
.\scripts\dev.ps1 -Action analyze
.\scripts\dev.ps1 -Action test
.\scripts\dev.ps1 -Action windows
.\scripts\prepare-signing.ps1
.\scripts\dev.ps1 -Action android
```

脚本使用 `P:` 临时盘符别名绕过上游 SDK 对空格的处理问题。没有修改系统开发者模式；本地 Flutter 支持预先创建的插件目录联接。全部开发进程退出后可用 `subst P: /d` 释放别名。

领域层包含纯 Dart 计时状态机与北京时间报告。数据层使用 Drift / SQLite。Android Kotlin 服务拥有计时与 Media3 播放器，使用单调时钟和 AtomicFile 日志；Flutter 入库后才确认事件，重复事件按 UUID 去重。Windows 使用 Stopwatch、media_kit、系统托盘与原生睡眠事件，在到期处理前检查睡眠标志。

发布验证状态见上级 `releases/VALIDATION.md`。编译与自动测试通过，不表示 Android 真机锁屏、电池策略、所有编码或 25 分钟实跑均已通过。
